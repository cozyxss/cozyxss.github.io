# about

Hi, I'm Betül {% include "syms.njk" %}, also known as **cozyxss**.

I'm a computer engineer working on IT support and systems, and learning web security along the way. This blog is where I write down what I learn: PortSwigger labs, CTF writeups, bug bounty notes and the lessons that came with them.

**What you'll find here**

- **web vulns** — my notes on each vulnerability type, topic by topic (starting with access control)
- **burp** — small Burp Suite tricks that save time while solving labs

I write my notes in Turkish, and every post is also available in English. Use the **EN / TR** switch at the top.
